# Riha Begum — Dark Chocolate Portfolio

A responsive React + Vite portfolio styled with Tailwind CSS and a Dark Chocolate / Mocha / Champagne Gold palette.

## Getting started

```bash
npm install
npm run dev
```

## Before publishing

- Add your real CV as `public/Riha-Begum-CV.pdf`.
- Replace placeholder contact details in `src/components/Contact.jsx`.
- Verify GitHub links in `src/components/Projects.jsx`.
- Add each project's real live-demo URL when available.
- Run `npm run build` before deploying.
